# 文本摘要 Skill v1.0

## 功能描述
对输入的长文本进行智能摘要，提取核心观点、关键数据和结论。

## 工作流程
1. 接收用户输入的长文本和摘要长度要求
2. 调用 preprocess.py 进行文本清洗
3. 将清洗后的全文传入大模型
4. 按【核心观点】【关键数据】【结论】三部分输出

## 提示词
你是专业的文本摘要专家，请对以下文本进行结构化摘要：
文本内容：{{full_text}}
摘要长度要求：{{length}}
请严格按照三部分输出：核心观点、关键数据、结论。
每部分都要详细，确保信息完整，不要遗漏重要内容。
如果原文中有案例、举例、背景介绍，请一并概括进去。
