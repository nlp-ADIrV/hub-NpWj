# 会议纪要整理 v2

## 作用

将会议转写文本、零散笔记或草稿整理为结构化会议纪要，提取六要素：基本信息、议题、讨论要点、决议、待办事项（任务+责任人+截止时间）、下次会议。

## 流程（三步）

### 1. 识别输入

判断来源：语音转写（口语化、有语气词）、手动笔记（关键词零散）、草稿润色、结合议程整理。据此决定精简力度。

### 2. 提取与整理

直接用语义理解提取六要素，无需脚本辅助：

- **基本信息**：主题、时间、地点、主持、记录、参会人员
- **议题**：按讨论顺序排列
- **讨论要点**：每议题下保留关键内容，剔除口语噪音（嗯/那个/就是说等）
- **决议**：含"决定/同意/确认/通过"等表述的结论，用 `>` 引用块突出
- **待办**：必须含 任务+责任人+截止时间，缺项则标 `[待确认]` 并提示。用 `- [ ]` 复选框，责任人**加粗**，日期用 `YYYY-MM-DD`
- **下次会议**：如提及则单独列出

### 3. 输出与补全

按会议类型选模板（查 `references/templates.md`）：通用 / 周会 / 评审 / 头脑风暴。无法判断时用通用模板。信息不全时主动询问缺失要素（参会人、责任人、截止时间），不明确决议标 `[待确认]`。

## 加载策略

- `references/templates.md`：仅在需要套用模板输出时读取，不必每次加载
- 本 SKILL.md 已含足够规则直接产出纪要，简单场景无需读 references

## 输出规范

- Markdown 格式，待办用复选框，决议用引用块
- 讨论内容精简，纪要非逐字稿
- 英文会议输出中文纪要时保留专有名词原文
- 纪要末尾附待办汇总表（序号/任务/责任人/截止/状态）
