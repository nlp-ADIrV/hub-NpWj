# 会议纪要模板

按会议类型选用，无法判断时用通用模板。

## 1. 通用会议

```markdown
# 会议纪要：{主题}

**时间**：{YYYY-MM-DD HH:MM-HH:MM}
**地点**：{地点/链接}
**主持人**：{姓名}
**记录人**：{姓名}
**参会人员**：{姓名列表}

---

### 议题一：{议题}

#### 讨论要点
- {要点}

#### 决议
> {决定}

#### 待办
- [ ] {任务} — **{责任人}** — {截止}

### 议题二：{议题}
（同上）

---

## 待办汇总

| 序号 | 任务 | 责任人 | 截止时间 | 状态 |
|------|------|--------|----------|------|
| 1    |      |        |          | 待开始 |
```

## 2. 周会/例会

强调上周待办回顾 + 本周汇报 + 新增待办。在通用结构前加：

```markdown
## 上周待办回顾

| 序号 | 任务 | 责任人 | 截止 | 状态 | 备注 |
|------|------|--------|------|------|------|
| 1    |      |        |      | ✅/⏳/❌ |  |

## 本周工作汇报

### {成员}
- 上周完成：{}
- 本周计划：{}
- 需要支持：{}
```

## 3. 评审会议

强调评审意见与结论。核心结构：

```markdown
# {评审类型}评审纪要：{对象}

**时间/地点/主持/记录/汇报人/评审专家**：{}

## 评审对象概述
{}

## 评审意见

### {专家}
- 意见：{}
- 建议：{}

### 共性问题
1. {}

## 评审结论
> {通过/有条件通过/不通过/需复审}
> 条件：{}

## 后续待办
- [ ] {修改项} — **{责任人}** — {截止}
```

## 4. 头脑风暴

保留更多原始想法，用 💡 标记。

```markdown
# 头脑风暴纪要：{主题}

**时间/地点/主持/记录/参与人员**：{}

## 背景与目标
{}

## 想法收集

### 方向一：{方向}
- 💡 {想法} — {提出人}

### 方向二：{方向}
（同上）

## 票选结果

| 方案 | 得票 | 提出人 |
|------|------|--------|

## 后续行动
- [ ] {待深化方向} — **{责任人}**
```

## 选用建议

| 会议类型 | 模板 |
|----------|------|
| 临时沟通、项目对接 | 通用 |
| 团队周会、部门例会 | 周会 |
| 方案/技术评审 | 评审 |
| 创意讨论、需求发散 | 头脑风暴 |
